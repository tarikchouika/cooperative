أنشئ نظام محاسبة متكامل للتعاونيات بواجهة عربية احترافية.

التقنيات: Next.js 14 App Router + TypeScript + Tailwind CSS + Prisma SQLite + Recharts + React Hook Form

الصفحات:
1. لوحة تحكم: إحصائيات + رسوم بيانية + آخر المعاملات
2. الأعضاء: إضافة/تعديل/حذف + بحث + ملف شخصي
3. المعاملات: إيداع/سحب/تحويل + فلتر + إجماليات
4. الصندوق: رصيد + حركات يومية
5. التقارير: شهري + كشف حساب عضو
6. الإعدادات: معلومات الجمعية + العملة

التصميم: واجهة عربية RTL، sidebar داكن أزرق، تصميم عصري احترافي، متجاوب.

أعطني الكود الكامل الجاهز للنشر.

إن إنشاء نظام محاسبي "كامل وجاهز للنشر" يتطلب آلاف السطور من الكود وقاعدة بيانات مهيأة، ولكن سأقوم ببناء الهيكل الأساسي والاحترافي (Core Architecture) للنظام باستخدام التقنيات التي طلبتها.

سأقدم لك هيكل المشروع، مخطط قاعدة البيانات (Prisma)، وأهم المكونات (Dashboard & Transactions) بتصميم عصري يدعم العربية (RTL).

1. إعداد قاعدة البيانات (Prisma Schema)

هذا المخطط يدعم الأعضاء، الصندوق، والمعاملات.

// schema.prisma
datasource db {
  provider = "sqlite"
  url      = "file:./dev.db"
}

generator client {
  provider = "prisma-client-js"
}

model Member {
  id          String        @id @default(cuid())
  name        String
  email       String        @unique
  phone       String
  balance     Float       @default(0.0)
  joinDate   DateTime      @default(now())
  transactions Transaction[]
}

model Transaction {
  id          String   @id @default(cuid())
  amount      Float
  type        String   // "DEPOSIT" | "WITHDRAW" | "TRANSFER"
  date        DateTime @default(now())
  memberId    String?
  member      Member?  @relation(fields: [memberId], references: [id])
  description String
}

model CoOpSettings {
  id          Int    @id @default(1)
  name        String // اسم الجمعية
  currency    String @default("SAR")
  logo        String?
}

4. نموذج المعاملات (Transactions Form)

استخدام React Hook Form للتحكم في البيانات.

// components/transactions/TransactionForm.tsx
"use client"
import { useForm } from 'eact-hook-form';

interface TransactionFormProps {
  onSubmit: (data: any) => void;
}

export default function TransactionForm({ onSubmit }: TransactionFormProps) {
  const { register, handleSubmit, reset } = useForm();

  return (
    <form onSubmit={handleSubmit(onSubmit)} className="space-y-4 bg-white p-6 rounded-xl shadow-md">
      <div>
        <label className="block text-sm font-medium text-gray-700 mb-1">نوع المعاملة</label>
        <select {...register("type")} className="w-full p-2 border rounded-lg focus:ring-2 focus:ring-blue-500 outline-none">
          <option value="DEPOSIT">إيداع (+)</option>
          <option value="WITHDRAW">سحب (-)</option>
          <option value="TRANSFER">تحويل</option>
        </select>
      </div>

      <div>
        <label className="block text-sm font-medium text-gray-700 mb-1">المبلغ</label>
        <input 
          type="number" 
          step="0.01"
          {...register("amount", { required: true })}
          className="w-full p-2 border rounded-lg focus:ring-2 focus:ring-blue-500 outline-none"
          placeholder="0.00"
        />
      </div>

      <div>
        <label className="block text-sm font-medium text-gray-700 mb-1">اسم العضو</label>
        <input 
          {...register("memberId")}
          className="w-full p-2 border rounded-lg focus:ring-2 focus:ring-blue-500 outline-none"
          placeholder="بحث عن عضو..."
        />
      </div>

      <button 
        type="submit"
        className="w-full bg-blue-600 text-white py-2 rounded-lg hover:bg-blue-700 transition-colors font-bold"
      >
        تأكيد المعاملة
      </button>
    </form>
  );
}

5. ملف التنسيق الرئيسي (Global CSS)

لضمان دعم الـ RTL بشكل مثالي.

/* globals.css */
@tailwind base;
@tailwind components;
@tailwind utilities;

body {
  @apply bg-gray-50 text-right;
  direction: rtl;
  font-family: 'Cairo', sans-serif; /* يفضل استدعاء خط Cairo من Google Fonts */
}

input, select, button {
  @apply text-right;
}
